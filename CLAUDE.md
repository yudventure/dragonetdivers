# Dragonet Divers — catatan untuk agen

Website dive center Dragonet Divers Raja Ampat (dragonetdivers.com). Pemilik berbahasa Indonesia: dokumentasi & komentar kode dalam Bahasa Indonesia, UI website English (default, di `/`) dan Bahasa Indonesia (di `/id`).

## Stack & perintah
- Next.js 16 App Router (JavaScript, bukan TypeScript), React 19, Tailwind CSS 4, MySQL via `mysql2`.
- `npm ci` · `npm test` (node:test di `tests/`) · `npm run build` (`next build --webpack`, wajib webpack untuk Hostinger) · `npm run dev`.
- Jalankan `npm test && npm run build` sebelum push; CI menjalankan hal yang sama (cek **build**).

## Struktur
- **Dua bahasa**: halaman publik di `app/[lang]/` (root layout, `<html lang>`), `proxy.js` menulis ulang alamat English ke `/en/...` di belakang layar dan mengalihkan `/en/...` ke alamat tanpa awalan (aturan di `src/lib/i18n.js`, `localeRoute`). Tautan internal selalu lewat `localeHref(lang, "/...")`. **Pilihan bahasa diingat**: tombol EN / ID memakai `chooseLangHref` (menambah `?lang=xx`), proxy menyimpannya di cookie `dd_lang` setahun lalu mengalihkan alamat berbahasa lain ke bahasa pilihan (`languageChoice`, diuji `tests/i18n.test.js`), jadi tautan `/id` dari riwayat peramban, email, atau admin tetap English bagi tamu yang memilih English; pengunjung tanpa pilihan (dan Google) memakai alamat apa adanya. Teks antarmuka di `src/content/ui.js` (`en` dan `id` berkunci sama, dijaga `tests/i18n.test.js`); isi layanan, FAQ, langkah perjalanan, galeri, dan teks peta juga punya versi `en`/`id`. Setiap komponen halaman menerima prop `lang`. Bahasa Indonesia memakai sapaan "kamu". Teks baru wajib ditulis dalam kedua bahasa.
- `/admin` punya root layout sendiri (`app/admin/layout.jsx`, Bahasa Indonesia saja). Alamat yang tidak ada → `app/[lang]/[...missing]` → `app/[lang]/not-found.jsx` (404 dalam bahasanya; karena root layout ada di segmen dinamis, Next.js menggambarnya di peramban, status tetap 404).
- **Menu** (`SiteHeader.jsx` + `SiteNav.jsx`): desktop menu berlatar pil (Layanan berisi halaman layanan yang tampil, Titik selam, Galeri, Cara ke sini, FAQ), satu tombol bahasa & mata uang (daftar turun `PreferencesMenu`: bola dunia, EN, dan IDR bila dolar dinyalakan), Book a dive; ponsel/tablet panel layar penuh (Layanan sebagai daftar turun, baris menu bergaris, bahasa EN | ID dan mata uang IDR | USD ringkas). Halaman mengirim `path` tanpa awalan bahasa ke `SiteHeader` untuk tombol EN / ID.
- **Mata uang** USD / IDR: kurs harian ECB lewat Frankfurter (`src/server/exchange-rate.js`, cache 12 jam) atau `USD_IDR_RATE` dari hPanel; logika di `src/lib/currency.js`. Pilihan tamu disimpan di localStorage (`src/components/currency.jsx`, `CurrencyProvider` di layout; awal Rupiah di semua bahasa, `DEFAULT_CURRENCY`). Pilihan dolar hanya ada bila tim menyalakan **Tampilkan pilihan dolar AS** di `/admin/kontak` (`showUsd` di `settings` baris `site`, bawaan mati); selama mati semua harga hanya Rupiah dan pilihan mata uang disembunyikan (`usd` di context, `UsdNote` untuk teks khusus dolar). Harga kelak ditulis dalam Rupiah dengan `<Price idr={1500000} />` (USD tampil sebagai perkiraan). Kurs hari ini juga tampil di jawaban FAQ uang tunai (`rate: true`).
- **Paket & checkout** (acuan: checkout Zanclus `SlotCalendar`/`ActivityDetail` di branch live Zanclus): paket per layanan di MySQL (`packages`, diisi tim di `/admin/paket`), tampil di halaman layanan (`ServicePackages.jsx` + `src/components/booking/ServiceBooking.jsx`, seksi `#packages`) dengan tombol **Add to cart** (lalu jumlah tamu − n +, di minimal − mengeluarkan paket) dan **Book now**. Di samping daftar ada **kalender tempat** (`booking/SlotCalendar.jsx`: sisa tempat per tanggal, Available / Almost full / Full / Closed, keadaan dari `src/lib/slots.js`, data `serviceSlots()` di `src/server/admin-data.js` → `slotCalendar()` di `src/lib/modules/calendar.js`, hanya angka tanpa nama), bilah keranjang di bawah layar, dan **jendela checkout** `<dialog>` (`booking/CheckoutDialog.jsx`): langkah 1 paket + tanggal dari kalender tempat + data pemesan (nomor WhatsApp lewat pemilih kode negara `booking/PhoneField.jsx`: bendera, nama negara dari `Intl.DisplayNames`, bisa dicari, nomor yang ditempel dengan +kode memindahkan negara; data dan logika `src/lib/phone.js` dari metadata libphonenumber-js, diuji `tests/phone.test.js`), langkah 2 ringkasan + cara bayar (kartu yang bisa diklik; transfer menampilkan rekening dengan tombol salin, tunai menampilkan jumlah yang disiapkan). Satu pesanan = satu layanan dan satu tanggal; tamu yang memakai tempat = jumlah tamu terbesar di pesanan itu (`partySize`). Keranjang di localStorage (`src/components/cart.jsx`, logika `src/lib/cart.js`, diuji `tests/cart.test.js`, maks. `MAX_ITEMS` paket), halaman layanan hanya memakai paket layanannya, disegarkan dari `/api/cart`. `/checkout?add=<id>` dan `/checkout/<id>` lama dialihkan ke halaman layanan paketnya (membuka checkout). Checkout → `/api/checkout` (`items`, `validateCart`) → satu pesanan (`orders`, kolom paketnya ringkasan dari `summarizeItems`) dengan rincian per paket di `order_items` (migrasi 007; kalender, kapasitas, dan buku kas membaca per paket lewat `ordersForDates`/`paidOrdersBetween`) lalu Midtrans Snap, PayPal Orders v2 (ditagih USD dengan kurs hari itu), transfer bank, atau **tunai di dive center** (`cash`, menyala sejak awal, `DEFAULT_PAYMENTS`; tanpa batas waktu bayar dan tanpa pengingat, halaman pesanan menampilkan alamat dari `/admin/kontak`); status tamu di `app/[lang]/order/[code]?t=<token>`. Logika murni di `src/lib/checkout.js` (validasi, total, status), server di `src/server/checkout.js`, `midtrans.js`, `paypal.js`, `orders.js`, `packages.js`, `payment-settings.js` (tabel `settings`). Notifikasi Midtrans `/api/payments/midtrans` (tanda tangan SHA512 + cek status + cocok jumlah); PayPal kembali ke `/api/payments/paypal/return|cancel`. Total selalu dihitung ulang di server. Key hanya di hPanel (`MIDTRANS_SERVER_KEY`, `MIDTRANS_PRODUCTION`, `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_MODE`); cara bayar, rekening (bank, nomor, atas nama, SWIFT/BIC opsional untuk transfer dari luar negeri), dan batas waktu di `/admin/pembayaran`; rekening BRI dari pemilik (`src/content/bank-account.js`) dimasukkan sekali dan transfer dinyalakan (`ensureBankAccount` di `src/server/payment-settings.js`, logika `withOwnerAccount`, dipanggil `instrumentation.js`, `paymentOptions()`, dan `/admin/pembayaran`; penanda `settings` baris `bank_account_<version>` supaya rekening yang diubah atau dihapus tim tidak kembali); transfer dan tunai (`MANUAL_METHODS`) ditandai lunas oleh tim di `/admin/pesanan` (tombol **Tandai lunas** / **Tunai diterima**, `adminSetStatus`), lalu masuk buku kas sebagai transfer / tunai. Paket dan harga hanya dari tim lewat admin, jangan ditulis di kode. Pengecualian: daftar harga 2026 yang diberikan pemilik (PDF Turtle Dive Homestay Price List 2026) ada di `src/content/price-list.js` (diuji `tests/price-list.test.js`) dan dimasukkan ke tabel `packages` sekali secara otomatis (`ensurePriceList` di `src/server/packages.js`, dipanggil `instrumentation.js`, halaman layanan, dan `/admin/paket`; penanda `settings` baris `price_list_<version>` supaya paket yang dihapus tim tidak kembali). Halaman layanan dirender per permintaan (`connection()`) supaya perubahan paket langsung tampil.

## Git & deploy
- `main` = produksi; Hostinger membangun dari `main`. Kerjakan di branch lain.
- **Setiap push ke branch selain `main` yang lulus test + build otomatis digabung ke `main` dan tayang** (job `merge` di `.github/workflows/ci.yml`, lalu job `deploy` → `.github/workflows/deploy.yml` → `scripts/hostinger-deploy.mjs` lewat API Hostinger, secret `HOSTINGER_API_TOKEN`). Push hanya pekerjaan yang sudah selesai dan teruji; percobaan pakai branch `wip/…`.
- Panduan Hostinger, DNS, dan MySQL: `HOSTINGER-DEPLOY.md`.
