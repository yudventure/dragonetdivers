# Dragonet Divers — catatan untuk agen

Website dive center Dragonet Divers Raja Ampat (dragonetdivers.com). Pemilik berbahasa Indonesia: dokumentasi & komentar kode dalam Bahasa Indonesia, UI website English (default, di `/`) dan Bahasa Indonesia (di `/id`).

## Stack & perintah
- Next.js 16 App Router (JavaScript, bukan TypeScript), React 19, Tailwind CSS 4, MySQL via `mysql2`.
- `npm ci` · `npm test` (node:test di `tests/`) · `npm run build` (`next build --webpack`, wajib webpack untuk Hostinger) · `npm run dev`.
- Jalankan `npm test && npm run build` sebelum push; CI menjalankan hal yang sama (cek **build**).

## Struktur
- **Dua bahasa**: halaman publik di `app/[lang]/` (root layout, `<html lang>`), `proxy.js` menulis ulang alamat English ke `/en/...` di belakang layar dan mengalihkan `/en/...` ke alamat tanpa awalan (aturan di `src/lib/i18n.js`, `localeRoute`). Tautan internal selalu lewat `localeHref(lang, "/...")`. Teks antarmuka di `src/content/ui.js` (`en` dan `id` berkunci sama, dijaga `tests/i18n.test.js`); isi layanan, FAQ, langkah perjalanan, galeri, dan teks peta juga punya versi `en`/`id`. Setiap komponen halaman menerima prop `lang`. Bahasa Indonesia memakai sapaan "kamu". Teks baru wajib ditulis dalam kedua bahasa.
- `/admin` punya root layout sendiri (`app/admin/layout.jsx`, Bahasa Indonesia saja). Alamat yang tidak ada → `app/[lang]/[...missing]` → `app/[lang]/not-found.jsx` (404 dalam bahasanya; karena root layout ada di segmen dinamis, Next.js menggambarnya di peramban, status tetap 404).
- **Menu** (`SiteHeader.jsx` + `SiteNav.jsx`): desktop menu berlatar pil (Layanan berisi kelima halaman layanan, Titik selam, Galeri, Cara ke sini, FAQ), tombol EN / ID, pilihan mata uang, Book a dive; ponsel/tablet panel layar penuh. Halaman mengirim `path` tanpa awalan bahasa ke `SiteHeader` untuk tombol EN / ID.
- **Mata uang** USD / IDR: kurs harian ECB lewat Frankfurter (`src/server/exchange-rate.js`, cache 12 jam) atau `USD_IDR_RATE` dari hPanel; logika di `src/lib/currency.js`. Pilihan tamu disimpan di localStorage (`src/components/currency.jsx`, `CurrencyProvider` di layout; awal English → USD, Indonesia → IDR). Harga kelak ditulis dalam Rupiah dengan `<Price idr={1500000} />` (USD tampil sebagai perkiraan). Kurs hari ini juga tampil di jawaban FAQ uang tunai (`rate: true`).
- **Paket & checkout** (acuan: checkout Zanclus): paket per layanan di MySQL (`packages`, diisi tim di `/admin/paket`), tampil di halaman layanan (`ServicePackages.jsx`, seksi `#packages`); checkout `app/[lang]/checkout/[id]` → `/api/checkout` → pesanan (`orders`) lalu Midtrans Snap, PayPal Orders v2 (ditagih USD dengan kurs hari itu), atau transfer bank; status tamu di `app/[lang]/order/[code]?t=<token>`. Logika murni di `src/lib/checkout.js` (validasi, total, status), server di `src/server/checkout.js`, `midtrans.js`, `paypal.js`, `orders.js`, `packages.js`, `payment-settings.js` (tabel `settings`). Notifikasi Midtrans `/api/payments/midtrans` (tanda tangan SHA512 + cek status + cocok jumlah); PayPal kembali ke `/api/payments/paypal/return|cancel`. Total selalu dihitung ulang di server. Key hanya di hPanel (`MIDTRANS_SERVER_KEY`, `MIDTRANS_PRODUCTION`, `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_MODE`); cara bayar, rekening, dan batas waktu di `/admin/pembayaran`; transfer ditandai lunas di `/admin/pesanan`. Paket dan harga hanya dari tim lewat admin, jangan ditulis di kode. Pengecualian: daftar harga 2026 yang diberikan pemilik (PDF Turtle Dive Homestay Price List 2026) ada di `src/content/price-list.js` (diuji `tests/price-list.test.js`) dan hanya dipakai panel **Daftar harga 2026** di `/admin/paket`, yang menambahkan paket yang belum ada sekali klik (`/api/admin/packages/import`, `importPackages`); setelah itu harga diubah di admin.
- `app/` halaman & route API; `app/api/health` untuk cek deploy + database; `app/api/conditions` kondisi laut live Selat Dampier (Open-Meteo, logika di `src/lib/sea-conditions.js`, cache 15 menit).
- `src/components/` komponen UI; `src/lib/site.js` data situs, kontak (email, alamat & titik base di Kurkapa, Mansuar), WhatsApp, dan media sosial (`NEXT_PUBLIC_INSTAGRAM` dst.); `src/lib/services.js` daftar layanan (grid beranda + halaman `app/[lang]/services/[slug]`, ilustrasi di `src/assets/services/<slug>.webp`).
- `src/lib/getting-here.js` + `GettingHere.jsx`: seksi "How to get here" (Sorong → Waisai → Kurkapa); peta rutenya `public/media/getting-here-map.svg` dibuat `node scripts/getting-here-map.mjs`.
- `src/content/gallery.js`: isi galeri beranda (foto di `src/assets/gallery/`, klip loop sendiri di `public/media/`, tautan YouTube/Shorts/TikTok/Instagram/Facebook dibaca `src/lib/video-embed.js`). Player pihak ketiga dimuat hanya saat petaknya terlihat (`EmbedVideo.jsx`).
- `src/components/peta-raja-ampat/`: peta Raja Ampat bersama (skill peta-raja-ampat, sama dengan DAMPIER & Zanclus); di beranda hanya titik selam & snorkel (`DiveSiteMap.jsx`, `src/lib/dive-map.js`, tema `.peta-dragonet`). Baca README di folder itu sebelum mengubah datanya.
- `/admin` dashboard tim (acuan: admin Zanclus): login operator `ADMIN_EMAIL` + `ADMIN_PASSWORD` dari hPanel, sesi cookie httpOnly bertanda tangan `SESSION_SECRET` (`src/server/admin-auth.js`, `src/lib/admin-session.js`, batas 5 percobaan/15 menit per IP). **Lupa password?** mengirim OTP 6 angka lewat email (`app/api/admin/password`, `src/lib/otp.js`); password baru disimpan scrypt di `settings` baris `admin_password` (`src/lib/admin-password.js`) dan berlaku sampai `ADMIN_PASSWORD` diganti. UI di `src/admin/` (kerangka `AdminShell.jsx` dengan menu berkelompok seperti Zanclus: tiap kelompok dropdown `<details>` yang terbuka bila berisi halaman aktif, di ponsel seluruh menu dilipat di balik tombol Menu; halaman tanpa sesi → `AdminGate.jsx`). API admin memakai `guardAdmin(request)`.
- **Modul admin** (acuan: Zanclus): Ringkasan cepat, Kalender reservasi (`/admin/kalender`), Tamu, Pesanan, Situs web (Paket & harga, Galeri foto & video `/admin/situs`), PR & mitra (Kalender konten, Agen & mitra), HRD (Pegawai, Absensi, Slip gaji), Keuangan (Pembayaran online, Buku kas, Laba rugi & pajak), Gudang (Barang & stok, Keluar masuk), Sistem (Mode developer). Catatannya disimpan di tabel umum `admin_records` (JSON per jenis, migrasi 006): skema tiap jenis di `src/lib/modules/*.js` diperiksa `cleanRecord()` (`src/lib/records.js`), disimpan lewat `src/server/records.js` dan API umum `/api/admin/records`; form dan tabel generik `src/admin/RecordManager.jsx`. Absensi dan slip gaji lewat `/api/admin/hr`. Data gabungan (kalender, tamu, buku kas dengan pesanan lunas otomatis, stok) di `src/server/admin-data.js`; pengaturan kecil (`calendar` kapasitas, `finance` pajak) di tabel `settings` (`src/server/settings.js`). Unduh Excel `/api/admin/export` (`src/lib/xlsx.js`, dari Zanclus). Tanggal tutup dan kapasitas harian dari kalender ikut diperiksa checkout (`checkAvailability` di `src/server/checkout.js`, pesan `closed`/`full` di `ui.js`).
- **Mode developer** (`/admin/developer`, acuan: Zanclus): tutup seluruh website, halaman (beranda, tiap layanan, checkout), atau bagian beranda. Pengaturan di `settings` baris `developer`, logika murni `src/lib/developer.js` (diuji `tests/developer.test.js`), dibaca `getDeveloper()` (`src/server/developer-state.js`, diingat per proses 15 detik). `proxy.js` menjawab halaman yang ditutup dengan `app/maintenance/route.js` (HTML mandiri `src/lib/maintenance-page.js`, teks `src/content/maintenance.js`, status 503 + Retry-After); operator dengan sesi sah tidak terkunci kecuali `?pratinjau=pengunjung` (cookie `dd_pratinjau` 30 menit, `?pratinjau=admin` untuk kembali). Bagian beranda yang ditutup diganti `LockedSection.jsx` lewat `developerView()` (`src/server/developer.js`), jadi beranda dirender per permintaan (`connection()`); `/api/checkout` menolak pesanan (`maintenance`). Bilah operator `DeveloperBar.jsx` hanya bertanya ke `/api/developer` bila ada cookie penanda `dd_operator`. `/order/*` tidak pernah ditutup.
- **Galeri beranda** dibaca dari `/admin/situs` (`src/server/site-gallery.js`); foto unggahan disimpan di tabel `media` (MEDIUMBLOB, diperkecil ke WebP dengan sharp, `src/server/media.js`, disajikan `/api/media/<id>`). Selama belum ada item aktif dipakai `src/content/gallery.js`.
- **Email** lewat SMTP dari hPanel (`src/server/mailer.js`, nodemailer, `SMTP_*`, sama dengan Zanclus). Kerangka HTML bermerek `src/lib/email-layout.js` (warna dari `brand/tokens.json`, satu tombol oranye, logo `public/media/email/`). Email tamu `src/lib/order-mail.js` + teks `src/content/order-mail.js` (en/id): `order` saat pesanan dibuat, `reminder` di tengah waktu bayar (`src/server/reminders.js`, dimulai `instrumentation.js`, cek status provider dulu), `paid` saat lunas; dicatat di tabel `order_emails` supaya tidak terkirim dua kali (`src/server/order-mail.js`). Pratinjau dan email uji di `/admin/pembayaran`.
- FAQ beranda: `src/content/faq.js` (fakta umum dicek ke sumber, tanpa harga/jadwal).
- Environment: baca nilai lewat `envText()` (`src/lib/env.js`); `-` berarti belum diisi, karena hPanel menolak value kosong dan pemilik mengimpor semua key sekaligus lewat **Impor .env** lalu mengisi value-nya sendiri. Key baru wajib ikut ditambahkan ke `.env.example` dan tabel di `HOSTINGER-DEPLOY.md`.
- `src/server/db.js` → pakai `query(sql, params)` untuk semua akses database (server saja).
- `database/migrations/NNN_nama.sql`: skema, idempoten (`CREATE TABLE IF NOT EXISTS`), dijalankan otomatis. Jangan ubah file migrasi yang sudah di-merge; buat nomor baru.
- `brand/`: identitas visual. Pedoman di `BRANDING.md`.

## Aturan brand (wajib)
- Dasar putih; warna hanya dari tema Tailwind di `app/globals.css` (palet bawaan Tailwind dimatikan): `teal`, `lagoon`, `mandarin`, `sunrise`, `ember`, `abyss`, `slate`, `foam`, `mist`, dst. `tests/brand-tokens.test.js` menjaga nilainya sama dengan `brand/tokens.json`.
- Judul `font-display` (Fredoka 600), teks `font-sans` (Plus Jakarta Sans).
- Satu tombol oranye (`bg-mandarin text-abyss`) per layar; teks putih di atas oranye dilarang.
- Logo di luar latar putih pakai `dragonet-divers-logo-plate.png` (pita tulisan file asli transparan).
- Jangan menulis harga, jadwal, atau klaim bisnis yang belum diberikan pemilik.

## Git & deploy
- `main` = produksi; Hostinger membangun dari `main`. Kerjakan di branch lain.
- **Setiap push ke branch selain `main` yang lulus test + build otomatis digabung ke `main` dan tayang** (job `merge` di `.github/workflows/ci.yml`, lalu job `deploy` → `.github/workflows/deploy.yml` → `scripts/hostinger-deploy.mjs` lewat API Hostinger, secret `HOSTINGER_API_TOKEN`). Push hanya pekerjaan yang sudah selesai dan teruji; percobaan pakai branch `wip/…`.
- Panduan Hostinger, DNS, dan MySQL: `HOSTINGER-DEPLOY.md`.
